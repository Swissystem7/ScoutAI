# Attic — archived proof scripts

`proof-demo.js`, `proof-match.js`, and `proof-tournament.js` lived at the
repository root and imported a `lib/` scoring engine that was later removed.

They are kept here only as historical artifacts. The engine those scripts
called is gone, so their printed rankings and pass/fail assertions are **not
reproducible** from this repository. Do not treat attic output as current
product evidence.

The live demo reads static PoC JSON (`poc-calibrated.json`) instead.
