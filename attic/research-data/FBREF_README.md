# FBref Big 5, 2024-2025

`fbref_big5_2024-2025.json` is public, derived football data harvested from FBref via the open-source `soccerdata` package. The JSON's `source` field records that provenance. The snapshot contains the flattened columns actually returned by FBref's standard table; optional expected/progression fields are not present in this harvest and the adapter does not invent them.
