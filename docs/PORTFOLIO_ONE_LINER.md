# ScoutAI — portfolio one-liner

## EN

ScoutAI is a **teaching lab** (Hebrew RTL browser demo): build a transparent football metric with provenance labels. It is **not** a scouting SaaS. Selling reports, rankings, or analysis derived from StatsBomb **Open Data** is forbidden by that licence. Any paid workshop runs only on **user-licensed data** (BYOD), never on Open Data.
